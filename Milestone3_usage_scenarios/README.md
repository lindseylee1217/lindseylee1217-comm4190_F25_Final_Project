# Milestone 3 — Usage Scenarios & Prompt Testing

## Overview
This folder documents how Looking Glass usage scenarios were designed, implemented, and evaluated. It includes notebooks for each teammate, prompt-testing CSVs, and sample data for quick runs.

## Contents
- Usage scenario notebooks  
  - `01_LL_usagescenario.ipynb` and `02_LL_usagescenario.ipynb` (Lindsey)  
  - `01_HG_usagescenario.ipynb` and `02_HG_usagescenario.ipynb` (Hanxi)
- Prompt testing data  
  - `looking_glass_prompt_testing.csv`, `looking_glass_prompt_testing_v2.csv`, `looking_glass_prompt_creative.csv`
- Sample inputs  
  - `sample_data/` simple text cases for varied tone/safety checks  
  - `sample_journals/` GPT-generated journal scenarios (students)  
  - `sample_writing/` creative writing samples

## How to use
1. Open any notebook to review prompts, responses, and annotations.  
2. Swap in files from `sample_data/`, `sample_journals/`, or `sample_writing/` to see sample data we used.  
3. Compare prompt-testing CSVs to see prompt iterations and outcomes.

## Notes
- Notebooks contain outputs for quick reading—no runtime setup required.  
- Data is lightweight and can be edited or extended for further experiments.
